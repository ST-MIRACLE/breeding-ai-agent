# 番茄育种AI自动化工作流

基于大模型API + 本地自动化工具，实现番茄种质实验数据的自动化处理，支持**果实品质数据**和**性状调查数据**两类数据类型。

## 解决痛点

育种科研人员处理大量种质实验数据（如果实品质测定、田间性状调查），人工整理耗时长、易出错。180份材料人工处理需6-7小时，本工具约40分钟完成（效率对比为估算值，口径见测试脚本）。

## 核心功能

### 双数据类型自动识别与处理

| 数据类型 | 字段数 | 核心字段 | 准确率 |
|----------|--------|----------|--------|
| 果实品质数据 | 10 | 果重、单果重、硬度均值、糖度均值、颜色、形状、萼片长度等 | 全量测试集约70%，清晰图片约85% |
| 性状调查数据 | 19 | 生长习性、裂果性、熟前果色、萼片形态、花序类型、首花节位等 | 经校验器交叉验证 |

### 图片直读（视觉大模型）

基于通义千问VL（qwen-vl-max）直接读取实验数据扫描图片，跳过传统OCR链路——"文字识别+表格理解+结构化提取"一步完成，识别结果经知识库校验（枚举值+数值范围）后输出结构化数据。

```
扫描图片 → 视觉大模型直读 → 知识库校验修正 → 结构化Excel
```

### 三层幻觉防护机制

1. **知识库约束**：内置番茄育种领域知识库，定义字段合法值与数值范围
2. **输出校验**：对大模型输出进行枚举值校验、数值范围校验、缺失字段补全
3. **多轮迭代**：通过few-shot示例和提示词调优持续优化输出质量

## 快速开始

### 环境要求
- Python 3.8+
- 依赖：pandas, openpyxl, requests

### 安装
```bash
pip install pandas openpyxl requests
```

### 运行

```bash
# 果实品质数据处理（自动识别数据类型）
python src/workflow.py --input data/raw/fruit_quality.csv --mock

# 性状调查数据处理
python src/workflow.py --input data/raw/trait_survey.csv --mock

# 指定数据类型运行
python src/workflow.py --input data/raw/fruit_quality.csv --type fruit_quality --mock
python src/workflow.py --input data/raw/trait_survey.csv --type trait_survey --mock

# 运行Mock模拟测试（演示用）
python tests/run_tests.py

# 运行真实API准确率测试（需API Key，使用手写表图片+Excel基准）
python tests/run_real_api_tests.py --api-key YOUR_KEY --image-dir 测试图片目录 --ground-truth-dir 基准Excel目录

# 图片直读模式（扫描图片 → 视觉大模型 → 结构化Excel）
python src/image_workflow.py --image data/raw/你的扫描图.jpg --api-key YOUR_KEY
```

### 接入真实大模型
```bash
# 通义千问
python src/workflow.py --input data/raw/fruit_quality.csv --api-key YOUR_API_KEY
```

## 核心成果

| 指标 | 数值 |
|------|------|
| 处理数据量 | 180份种质材料（仓库内含32份/类测试样本） |
| 人工耗时 | 6-7小时（按2.17分钟/份估算） |
| AI耗时 | 约45秒/张（qwen-vl-max推理），180份材料约15-20分钟 |
| 效率提升 | 约10倍 |
| 数据类型 | 果实品质 + 性状调查（自动识别） |
| 品质表准确率 | 全量测试集约70%（18张手写表/约190份材料，±0.5容差）；清晰规范图片约85% |
| 单字段最佳 | 个数 93.7%，萼片长度 81.6%，形状 80.2%，颜色 76.9% |

> 注：Mock模拟测试（`run_tests.py`）用于演示流程，非真实API结果。真实准确率以 `run_real_api_tests.py` 输出为准。低质量/潦草图片准确率显著低于清晰图片。

## 真实API测试方法

使用 `tests/run_real_api_tests.py` 对真实手写品质测定表进行端到端测试：
- **测试集**：18张扫描图片，覆盖约190份番茄材料（含251ZJ/252ZJ系列及山东杂交组合）
- **基准**：对应Excel录入数据（261汉南ZJ材料品质数据、261山东ZJ品质数据）
- **比对字段**：果重、个数、硬度均值、糖度均值、颜色、形状、萼片长度（7项）
- **数值容差**：±0.5（手写数据读数误差范围内）
- **耗时**：单张图片识别约45秒（qwen-vl-max推理）
- **结果**：全量18张整体约70%，其中14张清晰图片约83-85%，4张低质量/名称不匹配图片显著拉低均值

## 技术亮点

1. **双数据类型自动识别**：根据字段名自动判断果实品质或性状调查数据，无需手动指定
2. **领域知识库约束**：内置番茄育种知识库，包含字段定义、合法枚举值、数值合理范围
3. **编码自动转换**：性状调查数据的数字编码自动添加文字说明（如1→无限生长型）
4. **提示词迭代优化**：完成4轮提示词迭代——通用表格提取→育种领域专化模板→颜色/形状同义词归一化→空个数默认5的业务规则注入，准确率从初始约75%提升至约90%

## 数据字段说明

### 果实品质数据字段

| 字段 | 类型 | 说明 | 合法值/范围 |
|------|------|------|------------|
| 名称 | 文本 | 种质材料编号 | 如241FL-29-1G-5-1 |
| 果重 | 数值 | 总重量(克) | 1-200 |
| 个数 | 整数 | 果实数量 | 1-10 |
| 单果重 | 数值 | 单果平均重量(克) | 1-50 |
| 硬度均值 | 数值 | 果实硬度 | 3-20 |
| 糖度均值 | 数值 | 可溶性固形物(Brix%) | 3-15 |
| 颜色 | 枚举 | 成熟果实颜色 | 红/黄/粉/绿/绿熟/橙 |
| 形状 | 枚举 | 果实形状 | 卵圆/圆/长圆/桃/扁圆/高圆/梨 |
| 备注 | 文本 | 异常信息 | 如失水、黄曲严重 |
| 萼片长度 | 枚举 | 萼片长度分类 | 短/中/长 |

### 性状调查数据字段

| 字段 | 编码 | 说明 |
|------|------|------|
| 生长习性 | 1/2 | 1=无限生长型，2=有限生长型 |
| 裂果性 | 1/2/3 | 1=无，2=不易裂，3=易裂 |
| 果肩 | 1/2 | 1=有，2=无 |
| 熟前果色 | 1-5 | 1=绿白，2=浅绿，3=绿，4=深绿，5=紫 |
| 萼片形态 | 1-5 | 1=包被，2=平齐，3=上翘，4=直立，5=上卷 |
| 花序类型 | 1/2/3 | 1=单式，2=双歧，3=多歧 |
| 熟性 | 1/2/3 | 1=早熟，2=中熟，3=晚熟 |
| 生长势 | 1/2/3 | 1=强，2=一般，3=弱 |
| 首花节位 | 整数 | 第1-3花序着生节位，通常4-15节 |
| 花序间隔节位 | 整数 | 相邻花序间隔叶片数，通常1-6 |
